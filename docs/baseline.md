## 收敛设计口径（对话定案，开发契约）

- **产品形态**：两个程序 + 一个共享库，单解决方案交付。
  - `PackKit.Builder` 制作端（用户自用控制台）：添加安装包（多选/拖拽）→ 每包可编辑名称与静默参数（按文件头自动识别 NSIS/InnoSetup/MSI 给默认静默参数，未知留空=人工点下一步）→ 上移/下移定安装顺序 → 成品设置（标题、可选图标、输出路径）→ 打包生成成品 exe；支持工程文件保存/打开（换包后重开工程重打即可出新 exe，此即"更新"方式）。
  - `PackKit.Player` 成品端壳（交付给装机的单 exe）：.NET 8 self-contained 单文件；启动读自身尾部 payload → 展示清单（勾选、全选、搜索框、名称/大小）→ 勾选安装：按清单顺序**串行**逐个「解压该包到临时目录 → 有静默参数则静默运行、无则拉起人工点下一步 → 等退出 → 标 ✓/✗ → 下一个」→ 汇总展示，失败项可重试；整个程序以管理员运行（app.manifest requireAdministrator，一次 UAC，安装器继承提权）；窗口标题取清单 Title。
  - `PackKit.Core` 共享契约库：清单 schema（manifest.json）、payload 结构（zip + footer 偏移索引）、安装器类型探测（启发式，unknown 不猜测）。
- **裁剪项（用户明确决策，禁止开发中自行恢复）**：无目录扫描模式、无批量上传、无更新检测；换包 = 制作端重打包。~~无分组~~（**2026-10-09 用户决策推翻**：分组功能以手动管理模式回归，见迭代②）。
- **成品 exe 结构（契约）**：`[壳exe 字节][payload zip 字节][footer 32字节]`；zip 内含 `manifest.json` + `packages/{文件名}`；footer = 16 字节 magic + zipOffset(int64 LE) + zipLength(int64 LE)；Player 按需解压**被勾选**的条目，非整包解压。
- **界面**：布局/元素按主会话确认的两张 ASCII 草图（草图定稿文本见下节）；主题/控件风格按 WPF-UI 4.0.2 酌情；按钮高度统一、同语义同风格、唯一主 CTA。

## 验收基准（括号枚举即边界）

1. 制作端：添加/拖拽安装包入列，可编辑名称与静默参数，自动识别安装器类型并给默认参数（MSI/NSIS/Inno 识别不了=unknown+留空，不得瞎猜）；可排序、可删除；工程可保存/重开；可打包产出**单个**成品 exe；打包过程有进度显示。
2. 成品端：双击（提权）后呈现清单，多选/全选/搜索可用；点安装按顺序串行执行；每项状态可见（待装/安装中/完成/失败）；失败项可单独重试；全部完成有汇总。
3. 成品 exe 结构：尾部追加 payload 的 self-contained 单文件 exe **可正常启动**（框架行为已实证），可读回清单并按需解压勾选条目。
4. 构建证据：全解决方案 `-t:Rebuild` 0 error **0 warning**；发布脚本产出 dist 下 Builder/Player 两个单文件 exe。
5. 无服务端、无数据库、无 HTTP 面：simple-api-tester 不适用（按功能测试规范·进程内契约承载口径，以派发契约为准跳过并上抛未测项）。
